育て方の流れ（目安）

  1. 1. 置き場所
    LEDライトを置ける棚や窓辺を確保します。
  2. 2. 種まき・植え付け
    有機質の培養土に種や苗を植えます。
  3. 3. 水やり・光
    土の表面が乾いたら水やり、ライトはタイマーで管理。
  4. 4. 収穫
    葉物は数週間、ミニトマトは数か月が目安（品種・環境により異なります）。
